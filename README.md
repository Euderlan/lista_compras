## Running the App

Make sure you have Flutter installed (see the official installation guide) and that a device/emulator is available.

```bash
# 1. Install project dependencies
flutter pub get

# 2. Run the app on the default attached device (Android/iOS)
flutter run

# 3. (Optional) List available devices
flutter devices
#    Then run on a specific device by its ID
flutter run -d <device-id>

# 4. (Optional) Run the web version (requires web support enabled)
flutter run -d chrome

# 5. Run unit and widget tests
flutter test
```

You can also build release artefacts:

```bash
# Android APK
flutter build apk --release

# iOS (requires a macOS machine)
flutter build ios --release

# Web (generates a build folder)
flutter build web
```
